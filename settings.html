Data & Backup
Browser storage, export and reset

Records are stored in this browser and mirrored to the local server when it is running. Export a JSON backup before resetting, moving to another computer, or clearing browser data. Photographs are stored separately in IndexedDB and are not included in the JSON backup.

A reset erases every student, class, attendance, examination and mark.
